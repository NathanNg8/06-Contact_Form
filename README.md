# Contact Form

## Description

A responsive web-based Contact Form built with HTML5 and CSS3. The project features a clean and modern user interface with responsive layouts, interactive form elements, Font Awesome icons, and a professional contact information section.

---

## About This Project

This project was created to further develop and enhance my front-end web development skills, particularly in:

* Semantic HTML5 structure
* Modern CSS3 styling techniques
* Responsive web design
* CSS Grid and Flexbox layouts
* Form design and user experience (UI/UX)
* CSS animations and transitions
* Custom CSS variables
* Integrating Font Awesome icons
* Building clean, reusable front-end components

---

## Features

✨ **User Interface:**

* Clean and modern dark-themed design
* Responsive layout for desktop, tablet, and mobile devices
* Organized contact form
* Contact information section
* Font Awesome icons for improved usability
* Smooth hover animations and transitions

📝 **Form Components:**

* Name input
* Email input
* Optional phone number input
* Subject input
* Message textarea

🎨 **Design Features:**

* Responsive Grid layout
* CSS Variables for easy theme customization
* Card-style form container
* Smooth fade-in animation
* Interactive input focus effects
* Hover animations for buttons
* Mobile-friendly responsive design

🔧 **Technology Stack:**

* **Markup:** HTML5
* **Styling:** CSS3
* **Icons:** Font Awesome
* **Architecture:** Static Front-End (No JavaScript)

## How the Application Works

### Contact Form

* Users can enter their name, email address, phone number, subject, and message.
* Required fields ensure essential information is completed before submission.

### Responsive Layout

* The form automatically adjusts to different screen sizes using CSS Grid and media queries.
* The layout provides an optimal viewing experience across desktop, tablet, and mobile devices.

### User Experience

* Input fields highlight when focused.
* Buttons provide smooth hover animations.
* Icons help users quickly identify each input field.
* The form is displayed inside a modern card layout with subtle animations.
